# FrameCut · 视频裁剪

导入 AVI / MP4，自由框选视野、截取片段并导出。支持导入文件夹逐个处理；视频只在本机浏览器中处理。

2026-10-08 工作流更新：主窗口可切换“原视频 / 裁剪效果”，共享当前播放帧、时间字形和标尺布局，分别记住缩放；原标尺参考值和识别缩图直接可见，高级像素标定收起。

素材显示待导出、导出中、失败、待保存、已保存或已发起下载；“导出并下一个”仅在文件夹保存成功或发起浏览器下载后切换。文件夹写入失败保留生成结果，重试保存无需重新编码。进度区显示阶段、已用时及编码器实际帧数，失败提供对应重试及详情。

剪辑方案自动存入当前浏览器的本项目键；也可保存 / 载入 JSON 备份。刷新或换电脑后需重新选择原视频，按文件名、大小、首尾内容指纹及探测出的尺寸、时长、帧率匹配再恢复。方案只含编辑参数和匹配信息，不含视频、下载结果或文件夹授权；历史完成状态标为“上次”。普通下载只能确认已经发起，不能确认用户保存成功。

## 使用

1. 点击“导入视频”，或把文件拖入网页；也可点击左侧“导入文件夹”，一次加入文件夹与子文件夹里的 AVI / MP4。其他格式会自动忽略。
2. 在画面上按住鼠标拖动即可框选，再拖即可重画；边角可微调大小。需要平移选框时开启“移动选框”，Esc 返回框选。右侧可直接输入像素坐标与宽高；选择“1:1”可输入正方形边长。
3. 设置开始和结束秒数，或者用滑块定位后点击“当前帧设为起点 / 终点”。
4. 在“保存位置”中选择一次保存文件夹，再选择 MP4（通用、重新压缩）或 AVI（FFV1 无损编码），点击“导出视频”。后续导出自动保存到该文件夹；不选择文件夹时仍使用普通下载。

专用域名版本的保存位置按当前电脑、浏览器和网址记住；当前 githack 共享域名仅在本次页面记住目录授权，刷新后须重新选一次文件夹。剪辑方案恢复不包含此授权。浏览器若要求重新授权，允许访问已记住的文件夹即可，无需再选路径；Chrome 提供“每次访问均允许”时可以选中。更换电脑、浏览器、网址或清除网站数据后需要重新选择。网页只能显示所选文件夹名称，不能读取完整磁盘路径。可用“更换保存文件夹”或“恢复普通下载”调整。

已存在的同名文件不会覆盖，新增文件自动加 `(2)`、`(3)` 等编号。若写入失败，已生成的视频会保留到当前页面，可重新保存或使用普通下载，无需重新编码。文件夹权限在点击导出时检查；不支持目录保存的浏览器继续使用普通下载。专用域名可将目录句柄保存在本机 IndexedDB；githack 共享域名不持久保存目录句柄。不上传视频或保存位置。

点击“上一个视频 / 下一个视频”或左侧素材列表逐个查看。文件夹导入按相对路径自然排序（例如 2 在 10 前）；不同子文件夹中的同名视频分别保留，重复导入同一文件夹不会重复加入。每个视频分别自动保存裁剪位置、时间、比例、标注和导出设置；刷新后重新选择相同原文件即可恢复，也可用方案文件迁移到另一台电脑。导入仅建立列表，选中时才读取预览，不会同时解码整个文件夹。

画面上方的 ＋ / −、滑块或鼠标滚轮可放大到适应窗口的 8 倍，滚轮以鼠标所在位置为中心。开启“拖动画面”或按住空格拖动可以寻找视野；关闭后继续拖动裁剪框。“适应窗口”恢复完整画面。每个视频分别记住放大倍数与查看位置；预览缩放不会改变裁剪坐标、导出尺寸或帧率。

未压缩、无音频的 RGB AVI（24 位 BI_RGB）直接从本地文件读取当前帧播放，不再生成整段 MP4 预览；你提供的 5 个大 AVI 均使用此路径。仅保留当前帧与一个待显示帧，切换视频时释放旧帧。磁盘较慢时预览会跳帧以跟上播放时间；导出始终从原文件读取，保留原始帧率。浏览器支持的 MP4 继续原生播放；其他 AVI / MP4 仍采用 PNG 定位和转码播放预览。

## 限制

- 建议在电脑上的 Chrome / Edge 使用。首次加载约 31 MB 处理引擎。
- 单个输入文件须小于 2 GiB，这是当前 WebAssembly 引擎的限制。WORKERFS 按需读取原文件，避免将整个输入文件复制到处理内存。
- 输出暂存在浏览器内存中。可导出的大小取决于电脑与浏览器可用内存；较大的无损输出可缩小选区或缩短时间。不能保证任意尺寸与时长的视频都能在浏览器处理。
- 选框按原视频像素定位，对齐至偶数像素；时间边界以实际视频帧为准。界面帧步进按平均帧率估算，变帧率视频不保证每次恰好跨过一帧。
- AVI 是容器，不同编码的兼容性取决于随附 FFmpeg 解码器。输出 FFV1 AVI 建议使用 VLC 播放。
- 刷新或关闭网页会清除本次文件访问与未保存的导出结果；已保存的剪辑方案仍可在重新选择原文件后恢复。处理期间请保持网页打开。

## 本地运行 / 自行部署

需要 Node.js 18 或更新版本：

```sh
npm ci
npm run build
npm run preview
```

打开终端显示的 `http://127.0.0.1:4173`。`dist/` 为可部署的纯静态网站，支持子目录部署，不需要服务器转码或 API 密钥。请通过 HTTP(S) 打开，不能直接双击 HTML。

处理引擎从锁定的 npm 包生成，构建时拆成两个小于 25 MiB 的静态文件；浏览器加载后重新合并。应用处理功能不依赖运行时第三方 CDN。
