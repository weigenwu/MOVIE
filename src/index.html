使用说明

在“保存位置”中选择一次文件夹，后续导出会直接保存到那里；同名文件自动加编号，保留已有文件。当前电脑的这个浏览器会记住该文件夹，刷新或重开后无需重新选路径；如果浏览器要求确认，请允许访问。清除网站数据或使用另一台电脑后需重新选择。普通下载无法由网页记住保存路径。

画面上方的 ＋ / −、滑块或鼠标滚轮可放大至 8 倍。开启“拖动画面”或按住空格拖动来寻找视野，关闭后继续框选。“适应窗口”恢复完整画面。放大仅用于查看，导出尺寸由裁剪框决定。

  1. 导入一个或多个 AVI / MP4，点击左侧文件切换。
  2. 拖动选框内部移动；拖动边角调整大小；从选框外拖动可重新框选。也可以直接输入坐标和尺寸。
  3. 拖动时间滑块或输入秒数，确定开始与结束时间。
  4. 选择格式并导出，完成后点击“保存视频”。

未压缩、无声的 RGB AVI 可直接播放，无需等待生成预览。磁盘较慢时预览可能跳帧，导出保留原视频帧率。其他 AVI 或浏览器不能直接播放的视频，仍可逐帧查看；点击播放需先生成选定时间段的预览。最终导出始终使用原视频。

较大的视频建议用电脑处理。当前浏览器引擎限制单个输入文件小于 2 GiB；无损导出也可能受到可用内存限制。处理时请保持页面打开。首次使用需加载约 31 MB 的处理引擎。

MP4 会重新压缩；AVI 使用 FFV1 无损编码，文件可能较大，建议使用 VLC 播放。网页不上传视频。原始数据请自行保留。
